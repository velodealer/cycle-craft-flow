# Fix InspectABike report links pointing at inspectabike.lovable.app

## Root cause (confirmed)
The links aren't generated by us. InspectABike's API returns `report_url` values like
`https://inspectabike.lovable.app/bike/report/<id>` — that is InspectABike's own Lovable
preview domain. We store and display exactly what their API sends (`inspectabike-create`,
`inspectabike-sync`, `inspectabike-backfill` all save `remote.report_url` as-is).

The proper fix is on InspectABike's side (publish their app / set a custom domain so their
API returns the right URL). Until then, we can rewrite the domain on our side.

## What we'll build

1. **Configurable report-link base URL in Settings → Integrations (InspectABike card)**
   - New field: "Report link base URL" (e.g. `https://app.inspectabike.com`).
   - Saved into the `integrations` row settings for InspectABike.

2. **Rewrite on save**
   - In the shared InspectABike helper, when storing `report_url` (create, sync, backfill),
     replace the URL's origin with the configured base URL. If no base URL is configured,
     store the link unchanged.

3. **One-off fix for existing rows**
   - Update all existing `inspections.report_url` values, swapping
     `https://inspectabike.lovable.app` for the configured base URL.
   - Runs as part of the same change so BPS-CER-3001 and all others are corrected immediately.

4. **Ask InspectABike to fix the source** (user action, noted in the settings UI)
   - Once their API returns the correct domain, our rewrite can be cleared.

## Technical details
- Helper `rewriteReportUrl(url, base)` in `supabase/functions/_shared/inspectabike.ts`;
  called from create/sync/backfill before persisting.
- Base URL stored in `integrations.settings` for the InspectABike integration row.
- Small form addition to the InspectABike section of `SettingsPage.tsx`.
- SQL update to rewrite existing `report_url` origins.

## Open question
- What is InspectABike's correct public web address for reports? If unknown, we ship the
  setting and leave it blank (links unchanged) until they confirm it.
