# Shopify App Store — App details description

The listing was rejected because the App details description was too thin. The description is entered in the Shopify Partner Dashboard (not in the app's code), so the deliverable is the final text to paste in.

## Proposed description (490 characters, no links, no formatting)

```text
VeloDealer is a management system for bicycle shops and bike dealers. It automatically lists your bikes on Shopify with full specifications, photos, condition and pricing, and keeps each listing in sync with your stock. When a bike sells on Shopify, the sale is recorded in VeloDealer and the listing is ended on your other channels. If a bike sells elsewhere, its Shopify listing is ended automatically so you never oversell. Manage individual listings or let VeloDealer handle everything.
```

## Why it fits the guidelines

- Full sentences, plain language, no jargon or marketing fluff.
- States what the app does: auto-listing with specs/photos/pricing, stock sync, sale recording, automatic delisting.
- No URLs, no formatting, no statistics or unverifiable claims.
- 490 characters, under the 500 limit.

## Steps

1. Give the user the final text to copy.
2. User pastes it into Shopify Partner Dashboard → App setup / listing → App details (description field) and saves.
3. No code changes needed.
